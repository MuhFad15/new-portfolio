==========================================================================
 CONTOH-KODE.txt  |  KUMPULAN KODE SIAP SALIN UNTUK PORTOFOLIO FADHLI
==========================================================================
Cara pakai: cari bagian yang kamu mau (Ctrl+F, ketik nomornya, misal "5."),
salin kodenya, tempel di file yang disebutkan, lalu simpan dan refresh browser.

  DAFTAR ISI
   1. Menambah CARD PROJECT
   2. Mengganti gambar / tulisan card
   3. Menghapus card, mengurutkan card
   4. RATE card (animasi popup 1 sampai 5)
   5. TIPE katalog (Website / Design / tipe baru)
   6. BANNER katalog (gambar, tulisan, link, kecepatan geser)
   7. SKILL (tambah, hapus, ubah persen)
   8. TAG skill (tambah, ganti teks, hapus)
   9. EXPERIENCE (pengalaman)
  10. ABOUT (tabel Nama / Tinggal / dst)
  11. MENU navigasi
  12. EMAIL dan KONTAK
  13. FOTO PROFIL di Home dan teks perkenalan
  14. WARNA dan FONT
  15. ANIMASI popup (durasi, putaran, warna), gyroscope
  16. BUILD, UPLOAD, dan DEPLOY (Vercel)
  17. ERROR yang sering muncul dan cara memperbaikinya

ATURAN PENULISAN (berlaku untuk semua)
  - Satu data = satu blok.  Blok card / banner pakai kurawal  { ... }
    Blok skill / experience / about pakai kurung siku  [ ... ]
  - Antar blok dipisah koma  ,
  - Semua teks diapit tanda kutip  ' '
  - Angka (rate, persen) TANPA tanda kutip
  - Teks yang ada tanda kutip tunggal: tulis  \'  contoh  'Fadhli\'s project'
  - Tanda // di kode = catatan, tidak ikut dijalankan. Boleh dihapus.

 2. MENGGANTI GAMBAR / TULISAN CARD                FILE: projects.js

Langkah gambar:

  tools: 'HTML, CSS, JavaScript'

 4. RATE CARD (ANIMASI POPUP 0 SAMPAI 5)           FILE: projects.js
==========================================================================
Di blok project, baris:   rate: 4,
  rate: 0,   // SECRET : paling gila. Tampak 5 bintang -> glitch -> ERROR -> WARNING -> flash putih -> kartu berputar banyak sambil glitch, mengecil (menyerap) lalu membesar -> terbuka.
             //          Setelah itu tiap 5 detik glitch: gambar jadi tulisan ERROR sebentar (src/input.css, cari sec-imgerr).
             //          Bintang diganti "?" dan tulisan "Secret". Banyak lapisan efek di sekitar kartu.
  rate: 1,   // 1 Star : membalik sekali, sederhana
  rate: 2,   // 2 Star : berputar 2x, percikan kecil
  rate: 3,   // 3 Star : berputar 3x, kilatan + percikan
  rate: 4,   // 4 Star : berputar 4x, gelombang kejut, layar bergetar
  rate: 5,   // 5 Star : animasi KHUSUS + kartu holografik.
             //          Setelah terbuka, ketuk kartu = gambar keluar dari kartu
             //          (lompat keluar, lalu ke samping, lalu kembali) + ganti warna bingkai
Rate dihapus / salah isi = otomatis 3. (rate: 0 sengaja berarti Secret.)
Urutan / waktu fase Secret:  script.js, cari  const PHASES   (angka = milidetik)
Tulisan jendela error:       script.js, cari  const ERR_LINES

Mengganti NAMA rate ("1 Star", "5 Star", dst)       FILE: script.js
Cari tulisan:  const RATES
  const RATES = {
    1: { name: '1 Star', sparks: 0  },
    5: { name: '5 Star', sparks: 10 }     // sparks = jumlah percikan
  };

 8. TAG SKILL (label kuning kecil seperti "Belajar")   FILE: script.js
==========================================================================
Tag = bagian KE-4 di baris skill. Tidak diisi = tidak ada tag.

TAMBAH tag ke skill yang belum punya:
    ['CSS', 'Mengatur tampilan dan tata letak.', 80],           <- sebelum
    ['CSS', 'Mengatur tampilan dan tata letak.', 80, 'Mahir'],  <- sesudah

GANTI teks tag:
    ['Tailwind', 'Sedang dipelajari.', 55, 'Belajar'],   ->   ... 55, 'Hampir bisa'],

HAPUS tag:
    ['Tailwind', 'Sedang dipelajari.', 55, 'Belajar'],   ->   ['Tailwind', 'Sedang dipelajari.', 55],
    (atau isi dengan tanda kutip kosong:  55, ''],  )

Teks tag bebas, contoh: 'Belajar', 'Baru', 'Mahir', 'Favorit', 'Sedang dalam proses'.
Tag mengikuti warna emas situs. Ubah warnanya: cari tulisan "const tagOf" di script.js,
class bg-gold (terang) dan dark:bg-sun (mode gelap).

15. ANIMASI POPUP DAN GYROSCOPE
==========================================================================
a) TABEL RATE                                     FILE: src/input.css
   Cari tulisan:  TABEL RATE   (satu baris per rate)
     .gacha-wrap[data-rate="5"] { --glow: 255, 95, 160; --dur: 3.6s; --turns: 6; --flash: 1; --ff: .55; --qa: .7; }
       --dur    lama animasi (detik)           --turns  jumlah putaran (bulat, min 1)
       --glow   warna cahaya R, G, B           --flash  kilatan di kartu (0 sampai 1)
       --ff     kilatan layar penuh (rate 4-5) --qa     getaran layar (0 = diam)
   Setelah mengubah src/input.css jalankan  npm run build.

b) GYROSCOPE / GERAK KARTU                        FILE: script.js
   Cari tulisan:  const gyroMax
     [16, 10, 10, 10, 10, 13] = kemiringan maksimal HP untuk rate 0,1,2,3,4,5.
     [11, 7, 7, 7, 7, 10]     = untuk laptop. Makin besar makin miring (HP sengaja lebih besar).
   Cari tulisan:  const LIM = 30;
     Derajat miring HP untuk mencapai kemiringan maksimal.
     Makin KECIL = makin peka (HP tidak perlu dimiringkan jauh). Makin besar = lebih kalem.
   Cari tulisan:  * .07
     Kehalusan gerak (0.03 sangat lambat, 0.15 cepat).

c) KARTU rate 5 (tema warna bingkai)              FILE: src/input.css
   Cari tulisan:  TEMA KARTU rate 5
     .holo-frame[data-skin="1"] { --holo: linear-gradient(...); --hglow: rgba(...); }
   Ada 4 tema (0 pelangi, 1 emas, 2 tosca, 3 ungu). Ubah warna di sini.

16. BUILD, UPLOAD, DAN DEPLOY
==========================================================================
Perlu Node.js terpasang. Di folder proyek (yang ada package.json):

  npm install          # sekali saja, mengunduh Tailwind CLI
  npm run dev          # build otomatis tiap kali file disimpan (saat mengedit)
  npm run build        # build final (jalankan sebelum upload)

Kapan perlu build?
  - PERLU   : menambah class Tailwind baru di HTML/JS, atau mengubah src/input.css
  - TIDAK   : hanya mengubah teks, gambar, rate, skill, banner, dll. di projects.js / script.js

UPLOAD ke GitHub: semua isi folder, KECUALI node_modules/ (sudah di .gitignore).
Folder dist/ dan images/ HARUS ikut.

DEPLOY di Vercel: buat file  vercel.json  di root (sudah ada di folder ini):
  {
    "buildCommand": "npm run build",
    "outputDirectory": "."
  }
Atau di Project Settings > Build & Development Settings:
  Framework Preset = Other, Build Command = npm run build, Output Directory = .
Peringatan "npm warn install-scripts @parcel/watcher" dan "cache-dir" tidak
berbahaya, abaikan saja.

17. ERROR YANG SERING MUNCUL
==========================================================================
- Halaman kosong / daftar tidak muncul setelah mengedit
    -> koma atau tanda kutip kurang di baris yang baru diubah.
       Tekan F12 > Console, lihat nomor baris yang disebut error.
- Gambar card tidak muncul
    -> nama file tidak persis sama (besar/kecil huruf, .jpg vs .png, spasi),
       atau file belum ada di folder images/.
- Class Tailwind baru tidak berefek
    -> jalankan  npm run build  (bagian 16).
- Skill muncul tanpa tag padahal sudah ditulis
    -> tag harus bagian KE-4:  ['Nama', 'Keterangan', 55, 'Belajar']  (angka tanpa kutip).
- Tipe katalog tidak muncul di tombol / card tidak ikut terfilter
    -> category di project harus sama persis dengan nama di CATEGORIES.
- Popup tidak bergerak mengikuti HP
    -> gyroscope butuh HTTPS (Vercel / GitHub Pages sudah HTTPS). Di iPhone,
       izinkan "Gerakan & Orientasi" saat Safari bertanya.
- Vercel: "No Output Directory named public"
    -> pakai vercel.json di bagian 16.
