      Cerita saya

      Dari rasa penasaran, jadi kebiasaan.

      Semuanya bermula dari pertanyaan sederhana: bagaimana sebuah halaman web bisa dibuat? Dari situ saya mulai membuka HTML dan CSS, mencoba, salah, memperbaiki, lalu mencoba lagi. Perlahan, rasa penasaran itu berubah menjadi kebiasaan belajar yang menyenangkan.

      Sekarang saya bersekolah di SMA Plus Abu Dzar dan membagi waktu antara pelajaran dan eksperimen di depan layar. Saya suka melihat sebuah ide yang awalnya hanya di kepala berubah menjadi halaman yang bisa dibuka dan dipakai orang lain.

      Saya masih di tahap belajar, dan saya tidak menutupinya. Justru karena itu setiap project saya anggap sebagai latihan serius: dirapikan, dibuat nyaman di HP, dan diperbaiki sampai saya sendiri puas melihatnya.

      Ide selalu ada. Tugas saya belajar cukup banyak supaya bisa mewujudkannya. Muhammad Fadhli

      Cara saya bekerja

      Empat kebiasaan yang saya pegang di setiap project.

      01

      Struktur dulu

      Sebelum memikirkan warna, saya susun kerangka HTML yang jelas supaya mudah dibaca, dirawat, dan dipahami mesin pencari.

      02

      Nyaman di HP

      Tampilan saya cek di layar kecil lebih dulu. Teks terbaca, tombol mudah ditekan, dan tidak ada yang meluber ke samping.

      03

      Detail kecil

      Jarak, hover, transisi, sampai mode gelap. Hal-hal kecil inilah yang membuat sebuah halaman terasa dirancang, bukan sekadar jadi.

      04

      Terus diperbaiki

      Versi pertama jarang sempurna. Saya biasakan melihat ulang, merapikan kode, lalu memperbaikinya sedikit demi sedikit.

      FAQ

      Pertanyaan yang sering muncul.

      Apakah kamu menerima project dari luar?

      Terbuka untuk didiskusikan. Ceritakan kebutuhanmu lewat form kontak, lalu kita lihat apakah waktu dan kemampuan saya cocok.

      Kenapa memilih Tailwind CSS?

      Karena cepat untuk bereksperimen dan hasilnya konsisten. Saya bisa mengubah tampilan langsung di HTML tanpa bolak-balik ke file CSS.

      Apa yang sedang kamu pelajari sekarang?

      JavaScript dan pendalaman Tailwind CSS. Setelah itu saya ingin mulai menjajal dasar-dasar game development.

      Bagaimana cara menghubungi kamu?

      Lewat form di bagian Contact pada halaman utama. Pesannya akan membuka aplikasi email dengan teks yang sudah siap kirim.

      Punya ide? Ayo kita ngobrol.

      Entah untuk project, belajar bareng, atau sekadar bertukar pikiran soal web.
